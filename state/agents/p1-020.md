## FOUND
- LIVE DEFECT, now fixed: a Quickshell Process holds ONE pending command and a
  new assignment overwrites it. AgentService funnelled every notification
  through one, running `notify-send --wait` (which blocks until dismissed), so
  two notifications in one poll ran only the second and everything raised while
  one sat unread was destroyed except the newest. Six agents needing attention
  produced one notification. Measured, not assumed:
  tests/run-notify-spawn-test.sh. Live evidence: pid 1241444 blocked 4h50m.
- SessionInfo (apex-os apexd/apex-agent-core/src/protocol.rs:277) has NO parent
  or children field. P0-011 bridges subagent_start/stop into the daemon but
  hook::observe() flattens them to Working + a detail string, and
  client::publish_hook only carries {id, event, state, detail, native} —
  agent_id and agent_type are dropped at the CLI.
- Claude subagents are in-process, so /proc can never show them. Their only
  on-disk trace is /tmp/claude-<uid>/<project>/<session>/tasks/<id>.output,
  symlinks into ~/.claude/projects/.../subagents/agent-<id>.jsonl. Real (78 and
  65 of them live) but harness-internal and unstable; the hook is the supported
  channel.
- Sandboxed sessions run under `bwrap --unshare-pid` but the host /proc still
  sees every descendant, so a process tree from SessionInfo.pid works for MCP
  servers and tool processes across every adapter.
- Claude Code sends NO desktop notification for "input needed" on this machine:
  its OS notification channel resolves to no_method_available outside
  kitty/ghostty/iTerm, and inputNeededNotifEnabled/agentPushNotifEnabled are
  MOBILE push. The only notify-send in the binary is the re-auth one. So the
  three converging sources are apexd's state, apexd's pending-request feed, and
  the PTY idle rule — all inside APEX.
- CI IS ALREADY RED ON THE TIP, unrelated to this branch: the "Agent Center
  invariants" step greps for `\bsudo\b` and `control\.sock` across
  src/services/agents/*.qml, and P0-022's AgentHelpContent.qml quotes
  `sudo apex request approve` and documents $XDG_RUNTIME_DIR/apex-agentd/
  control.sock as help text. The check cannot tell a string literal in a help
  document from code.
