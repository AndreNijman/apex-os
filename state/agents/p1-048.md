apart is what stops diff agreeing with apply by construction."

### Against the eight acceptance criteria
1. plain-language opening — **missing**. Page opens on a file path.
2. primary actions obvious — **partial**. Preview ("Dry run") and Apply exist;
   Apply is section 10 of 11. "Use this device as Blueprint", Import,
   Sync/Export do not exist.
3. visual current-vs-desired diff — **partial**. Text rows `current → desired`.
4. grouped sections — **partial**. Desktop, Agent, Apps, Languages, Gaming.
   Modes, identities, cloud bindings absent.
5. raw TOML remains available — **unmet**. TOML is read-only display; there is
   no raw editing to keep.
6. destructive removals highlighted separately — **missing**. A removal renders
   identically to an addition.
7. transactional apply, reports rollback — **missing**. Runs `apex apply`,
   prints output.
8. useful empty state — **fails**. With no blueprint the editor sections still
   render and lead with internal vocabulary.
