## START FROM THIS CONSTRAINT — it is measured, not assumed

p1-053a finished and landed as merge `4ae4cf22`. Its closing finding is the
thing P1-056 has to be designed around:

**`apex-agent-core`'s `Request` enum has NO `profile` verb, NO `projects` verb
and NO `worktrees` verb.** That was read out of the enum, not remembered.
Round 3 of p1-053a had built a `{"cmd":"worktrees"}` request and a parser for
the answer; nothing on the other end could ever have parsed it, and the phone
would have shown an error where it offered a picker. It was removed, and a test
was kept and INVERTED so it cannot come back.

So a Projects/Workspaces/Worktrees UX either:
  (a) derives what it shows from what the daemon already reports
      (`Hello.agents`, and `RunRequest.worktree` does exist as a NAME), or
  (b) adds the verbs to the daemon — which is a protocol change, needs the
      desktop side, and is a much bigger unit than it looks.

Decide which, say so on the branch, and do not build a picker over a verb that
does not exist. If you choose (b), the socket's own tests are where it starts.

## Constraints that have already bitten this codebase

- **Every socket write must be off the main thread.** Android installs
  `StrictMode.enableDeathOnNetwork()` for every app targeting API 11+. It is
  not a flag and a debug build does not relax it. The first keystroke would
  have killed the process. Terminal io is on a single-thread executor (single,
  because a pool delivers `ls` as `sl`); view-model closes go to
  `Dispatchers.IO`. Nothing here can catch a regression: no JVM test reaches a
  Compose callback, and `assembleDebug` compiles code it never runs. Read for
  it.
- **NO device and NO emulator.** Headless only. `./gradlew :core:test
  :app:testDebugUnitTest :app:assembleDebug` with
  `JAVA_HOME=/usr/lib/jvm/java-21-openjdk ANDROID_HOME=/var/tmp/android-sdk`.
  Never open a window on Andre's desktop.
- The CI `android` job **has still never run**. Its path classifier has been
  run by hand against a diff; that is not the same thing.
- Mutation discipline: every new assertion must be watched going red against a
  mutated source, and the source restored **byte-identical with plain `cp`** —
  never `mv`, never `cp -p`; both preserve mtime and cargo/gradle then skip the
  rebuild, so the "restored" run is the mutant's own cached result.
