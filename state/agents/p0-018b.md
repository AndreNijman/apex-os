## FOUND
- The guard wrote `state reverted` regardless of whether `restore` succeeded, so
  an engine failure during the countdown left the machine on an unconfirmed
  layout with a record saying it had been put back — and `reconcile` believed it.
- A rollback naming an output unplugged mid-countdown made wlr-randr reject the
  whole invocation, leaving every OTHER output wrong.
- `apex-hypr-migrate` wrote converted user binds to the exact file the shell
  rewrites whole on every start, so a migrating user lost every custom keybind.
  Rescue script added. Separately, a rebind claimed only the new combo, so
  moving Terminal off SUPER+T left the old bind still opening one there.
- **212 `color:` bindings across src/ are `Qt.rgba(1, 1, 1, alpha)`**, 20 of them
  in settings pages including the description under every section heading. On
  matugen's light surface they are invisible, so shipping the Light/Dark toggle
  would have produced a blank Settings window. The toggle was removed; the
  mechanism stays, reachable by setting `"mode": "light"` in wallpaper.json.
  `check-color-tokens.sh` never saw them — it bounds hex literals and the n/255
  disguise, not that form. It now ratchets the 212 so the count cannot rise.
