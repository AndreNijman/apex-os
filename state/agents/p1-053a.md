## Toolchain, measured on this machine 2026-09-12 — do not re-derive

- `/usr/bin/java` and `/usr/bin/javac` are **OpenJDK 27-ea**. AGP does not
  support 27; you will need a supported JDK (21). `sudo apex install
  java-21-openjdk-devel` builds a systemd sysext and merges it live, no reboot.
- No `gradle`, no `sdkmanager`, no `~/Android`. Use the Gradle **wrapper** and
  the Android command-line tools. 918 GB free on `/var`, so size is not the
  constraint; your time is.
- **No emulator, ever.** The standing rule is headless-only and no window on
  Andre's desktop. Verify with `./gradlew assembleDebug` and JVM unit tests.

## What the desktop side already offers (from p1-052's card, measured)

`apex remote pair --text` prints only the `apex-remote:` payload on stdout.
`apex remote devices --json` → `id`, `name`, `public_key`, `paired_ms`,
`last_seen_ms`, `revoked_ms`, `requires_user_verification`, `last_path`.
`apex remote revoke <id>`, `apex remote status --json`. No `pair --json`.
The relay is deployed and verified at `apex-relay.andrenijman.com`; the wire
protocol and pairing live in `apexd/apex-remote-core/` (`wire.rs`, `pairing.rs`,
`noise.rs`, `identity.rs`, `relay.rs`) — that crate is the specification.
