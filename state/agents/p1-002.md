  obvious errno mapping reports a symlink as an absent file. Same class as

  classifies exactly. Fixed in 9af2b08 with a three-answer test.

  into BOTH the reply and the audit line UNSCRUBBED; `scrub_all` (:479) only
  covers `Ok(Performed).output`. A provider returning

  `perform` (:475) — i.e. after the value is read at :460 — leaks the
  credential to the caller and to the trail. Plan: never trip it in the

  `git push <remote>` which resolves the remote AGAIN in the child — so the
  URL the host pin checked is not provably the URL contacted.
