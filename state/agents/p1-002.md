  detail, so `bind` cannot hand what it resolved to `perform`. Cloudflare

  get-url`, perform runs `git push <remote>` which resolves again.

  mapping reports a symlink as an absent file. O_PATH|O_NOFOLLOW returns an
  fd to the LINK, so fstat classifies exactly.

  others: its result IS a credential (a wss:// URL that authorises the log
  stream). Session is created, URL withheld, stream not relayed.
