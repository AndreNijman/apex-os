## Findings the roadmap did not have

- `GITHUB_PERSONAL_ACCESS_TOKEN` in `~/.claude/settings.json` is 23 bytes of
  `[A-Z_]` shaped `REPLACE_WITH_ACTUAL_PAT`. A placeholder, never a token, so
  `plugin:github` has never authenticated once.
- That plugin's endpoint is `api.githubcopilot.com`, and `migrate.rs`'s
  `provider_for` pins any `GITHUB*` name to `github.com`. A migration would
  store the credential for a host the broker's pin can never carry it to.
- The plugin's server is defined in
  `~/.claude/plugins/cache/claude-plugins-official/github/unknown/.mcp.json`
  with `"Authorization": "Bearer ${GITHUB_PERSONAL_ACCESS_TOKEN}"`. Migration
  does not read that file, and removing the `env` entry it interpolates breaks
  the server silently.
- `claude-memory`'s bearer token is still in cleartext in `~/.claude.json` on
  this machine: migrate has never been run here.
